Set up two-step sign-in

Staff accounts can see every driver's location, so they need a second step at sign-in.

  1. Install an authenticator app on your phone, such as Google Authenticator, Microsoft Authenticator or 1Password.
  2. In the app, add an account and choose Enter a setup key. Use this key (time-based): … On a phone you can tap this link instead.
  3. Enter the 6-digit code the app shows.
